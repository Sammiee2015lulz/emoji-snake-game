# 🐍 Emoji Snake - Fun Cool Game

A simple, fun, and cool browser-based Snake game where you eat colorful emojis!

## How to Play

1. Open `index.html` in any web browser.
2. Use **Arrow Keys** or **WASD** to control the snake.
3. Eat the emojis to grow and score points.
4. Avoid walls and yourself!
5. Speed increases as you score more.
6. Click **Restart** to play again.

## Features

- Emoji food that changes randomly
- Smooth gameplay with increasing difficulty
- Score tracking
- Responsive controls
- Cool dark theme with neon vibes

## Technologies

- Pure HTML5, CSS3, and vanilla JavaScript
- HTML5 Canvas for rendering
- No dependencies or build steps required!

## Play Now

Just download or clone and open `index.html`. Or host it on GitHub Pages for easy sharing!
